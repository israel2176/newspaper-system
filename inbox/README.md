# תיבת הקבצים לעיבוד

לכאן נשמרים אוטומטית קובצי ה-PDF שמגיעים במייל לכתובת העיתון. מכאן הם הופכים לעמודים באתר, ואחרי העיבוד הם נמחקים מהתיקייה.

## העלאה ידנית, בלי מייל

1. בעמוד הזה ב-GitHub לוחצים **Add file ← Upload files**.
2. גוררים את קובץ ה-PDF.
3. לוחצים **Commit changes**.

תוך כ-3 דקות הגיליון מופיע באתר.

## שם הקובץ

- **מספר הגיליון** נלקח מהשם, למשל `גיליון 286.pdf`.
- **תאריך:** כדי לקבוע תאריך, מוסיפים אותו לשם, למשל `גיליון 286 2026-11-14.pdf`.
- **בלי מספר בשם:** הגיליון יקבל את המספר הבא אחרי הגיליון האחרון.

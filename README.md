# עמנואל שלי — עיתון אונליין

אתר העיתון, עם דפדפת עברית מימין לשמאל. כל גיליון שנשלח במייל עולה לאתר לבד.

**כתובת האתר:** https://newspaper-system.vercel.app

## איך זה עובד

1. **שולחים את העיתון במייל** לכתובת ייעודית בדומיין שלכם, למשל `paper@הדומיין`. הכתובת מוגדרת ב-Cloudflare.
2. **Cloudflare מקבל את המייל** ושומר את קובץ ה-PDF בתיקייה `inbox` שבמאגר.
3. **GitHub Actions ממיר את ה-PDF לעמודים:**
   - כל עמוד הופך לתמונה.
   - כפולות עמודים מפוצלות לשני עמודים, בסדר מימין לשמאל.
   - נוצרות תמונת שער ותמונות קטנות לכל עמוד.
   - רשימת הגיליונות מתעדכנת.
4. **Vercel מעדכן את האתר.** כל התהליך לוקח כ-3 דקות.

אין שרת לתחזק: Cloudflare, GitHub ו-Vercel חינמיים לשימוש כזה.

## הגדרה — פעם אחת

1. **Vercel** — כבר מחובר. כל שינוי בענף `master` מתפרסם לבד.
   כדי לחבר דומיין לאתר: Vercel ← הפרויקט ← **Settings ← Domains**.
2. **כתובת המייל ב-Cloudflare** — המדריך המלא נמצא כאן: [cloudflare/email-worker/README.md](cloudflare/email-worker/README.md).

## שימוש שוטף

- **רגיל:** שולחים את ה-PDF לכתובת העיתון, והגיליון מופיע באתר תוך כ-3 דקות.
- **בלי מייל:** מעלים PDF לתיקייה `inbox` דרך האתר של GitHub. פרטים בקובץ [inbox/README.md](inbox/README.md).
- **מספר הגיליון** נלקח מנושא המייל או משם הקובץ, למשל "גיליון 290". אם לא נמצא מספר, הגיליון מקבל את המספר הבא.
- **כמה גיליונות נשמרים:** באתר נשמרים 11 הגיליונות האחרונים. אפשר לשנות זאת עם המשתנה `MAX_ISSUES`:
  - איפה: במאגר ב-GitHub ← **Settings ← Secrets and variables ← Actions ← Variables**.
  - הערך `0` שומר את כל הגיליונות.

## הצופה

- **דפדוף:** אמיתי מימין לשמאל. השער מימין, ועמוד 2 בצד ימין של הכפולה.
- **תצוגה:** במחשב מוצגת כפולה, ובנייד עמוד אחד.
- **מעבר בין עמודים:** חיצים, החלקה, או גרירה של פינת הדף.
- **הגדלה:** לחיצה כפולה על עמוד או כפתור 🔍. אפשר להגדיל ולהקטין עם הכפתורים, עם Ctrl וגלגלת העכבר, או בצביטה בנייד.
- **כל העמודים:** כפתור שמציג תמונות קטנות של כל העמודים. לחיצה על תמונה עוברת לעמוד.
- **שיתוף:** כפתור לשיתוף העמוד הנוכחי בוואטסאפ, או להעתקת הקישור.
- **קישור ישיר לעמוד:** לדוגמה `/?issue=285&page=12`.
- **מקשים:**
  - חץ שמאלה או רווח: העמוד הבא.
  - חץ ימינה: העמוד הקודם.
  - `Z`: הגדלה.
  - `G`: כל העמודים.
  - `F`: מסך מלא.
  - `Esc`: חזרה.

## מבנה המאגר

| תיקייה או קובץ | מה יש בו |
|---|---|
| `public/` | האתר עצמו, שאותו Vercel מפרסם |
| `public/newspaper/` | הגיליונות: תמונות העמודים ורשימת הגיליונות (`manifest.json`) |
| `public/js/viewer.js` | הדפדפת |
| `cloudflare/email-worker/` | הקוד שמקבל את המיילים ב-Cloudflare |
| `scripts/newspaper_pipeline.py` | המרת PDF לעמודים |
| `inbox/` | לכאן מגיעים קובצי ה-PDF לפני העיבוד |
| `.github/workflows/` | התהליכים האוטומטיים ב-GitHub |

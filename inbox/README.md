# תיבת העלאה ידנית

רוצים לפרסם גיליון בלי מייל? מעלים לכאן קובץ PDF דרך GitHub:
**Add file → Upload files**, ואז **Commit changes**.

תוך כ-3 דקות הגיליון יעלה לאתר, והקובץ יימחק מכאן אוטומטית.

איך נקבעים פרטי הגיליון לפי שם הקובץ:
- מספר הגיליון נלקח מהשם, למשל `גיליון 286.pdf`.
- כדי לקבוע תאריך, מוסיפים אותו לשם בתבנית `286 2026-11-14.pdf`.
- אם אין מספר בשם, הגיליון יקבל את המספר הבא אחרי האחרון.

# עמנואל שלי

האתר של העיתון: https://newspaper-system.vercel.app

## פרסום גיליון
שולחים את ה-PDF לכתובת המייל של העיתון. אחרי כמה דקות הגיליון מופיע באתר.

אפשר גם להעלות את ה-PDF ידנית לתיקייה `inbox`.

## הגדרת המייל
ההגדרה הראשונית מוסברת ב-[cloudflare/email-worker](cloudflare/email-worker/README.md).
